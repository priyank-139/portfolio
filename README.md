# Priyank Upadhyay — DevOps Portfolio

A simple GitHub Pages portfolio for a Senior DevOps Engineer.

## Before publishing

1. Replace `https://github.com/` in `index.html` with your actual GitHub profile URL.
2. Review the experience dates and project descriptions.
3. Create a GitHub repository named exactly:
   `YOUR_GITHUB_USERNAME.github.io`
4. Upload `index.html`.
5. In GitHub: **Settings → Pages → Deploy from a branch → main → / (root)**.
6. Your portfolio will be available at:
   `https://YOUR_GITHUB_USERNAME.github.io/`
